## 一、 22 条 AI 原生导演工艺实战库（附 164 区块实测普及率）

### 模块 A｜战斗、暴力与多肢体交互（规避物理穿模与过审拦截）
1. **无接触“前摇 → 反应 → 结果”三段动作跳剪法**（`58/164` 区块）：砍掉肉搏身体接触中间帧，改拍 `靴底踹出/破门爆碎剪影 → 旁观者惊愕 → 敌人嵌墙/俯拍坠地`（`s01_015300`, `022200`, `s03_081400`）。
2. **黑白线稿 / 水墨泼墨“双色交替冲击帧”**（`82/164` 区块，**50.0%**）：经原片 5fps 实测验证，在 0.6 秒内交替插入 `0.15s 黑底白爆` + `0.10s 白底黑墨泼溅`（`s05_001400`），彻底掩盖近战关节断层。
3. **纯红底 + 纯黑剪影一闪瞬杀 + 俯拍双足留白**（`s03–s05` 高频升级技法）：斩杀/穿胸瞬间切 1 帧正红底纯黑剪影，下镜切上帝视角倒毙双足与地面微量血渍（`s03_061400`, `s04_041400`, `s05_070500`），兼顾美学、过审与省算力。
4. **烟雾 / 毒雾 / 血雾 / 沙尘 / 白闪 / 黑屏断层遮罩术**（`77/164` 区块，**47.0%**）：用满屏翻涌浓雾、黑洞涡流、白闪或 1 帧纯黑屏吞没形变与群战接缝，烟散即出结果态（`s02_053500`, `s04_025000`）。
5. **人兽/巨物“无本体隐形法”与“微距单点死锁”**：要么不建巨兽本体只拍巨浪与惊恐反应，要么死锁“单手抠眼眶/单手捏蟒颌”极近微距 + 强动态模糊甩头（`s01_054300`, `s03_081400`）。
6. **半透明发光法相 & 远程光轨对轰代偿实体拼刀**：多臂/巨兽神通以半透明光影法相叠在常规人体后方，空战用红青流光光轨追逐替代精细贴身拆招（`s01_045300`, `s02_041600`）。

### 模块 B｜文戏、口型同步与群像表演（全剧覆盖率最高的省算力体系）
7. **局部手/足/器物微距替代全身表演**（**`162/164` 区块，98.8% 全剧第一铁律！**）：用握剑、叩案、端茶、捻佛珠、滴蜡红烛、战靴踏石、第一人称双手入画（POV）切分 20–30 句/分的高密对话，让台词在画外 L-cut 流动（`s05_062500`, `084000`）。
8. **“以眼代口”眼/唇 ECU + 闭眼内省替代正面长口型**（**`144/164` 区块，87.8%**）：高频切至满框单/双眼 ECU（配 OS 独白零张嘴！）或仅拍闭眼微动、下颌唇部微距（`s05_071500`, `084800`）。
9. **物理道具遮嘴 & 无头构图免口型法**（**`132/164` 区块，80.5%**）：配角标配半脸青铜面具/深兜帽；文戏用**绿茶杯贴唇、折扇半遮面、抬手挡眼、全息 UI 面板挡嘴、背影 OTS、甚至腰部无头中景**自然遮蔽嘴部（`s02_040100`, `045400`, `050000`, `s05_063100`）。
10. **Q 版小人 / 肩头迷你分身外包夸张表情**（**`95/164` 区块，57.9%**）：把抓狂、暴怒挥剑、星星眼、捂脸羞愧、大笑崩溃全部外包给黑底聚光灯 Q 版或合成在肩头的迷你 Q 版小人，写实主模型零崩脸风险（`s02_024500`, `043100`, `s05_064500`, `074800`）。
11. **高位神秘角色“强圣光遮面留白”策略**（`s05_073900`）：顶级大佬全程藏于高阶尽头刺眼的金白体积圣光之后，只出声不露脸——零建模一致性负担且威压封神。
12. **天然前景容器遮挡下半身 & “人体背景墙”稳态群像**：借书桌、茶案、浴桶、马鞍遮掉腰部以下；小队采用 C 位 + 背后三角固定站位；百官/众僧采用大纵深中轴对称低头阵列微动定格（原片 5fps 实测证实：2.6 秒 OTS 镜头中躯干几乎完全静止，仅靠 2 像素呼吸微动 + 口型微张即可成立！）。

### 模块 C｜变身、换装、生活动作与宏大转场
13. **“局部渐进拼接 + 甩镜模糊”替代全身连续变身/穿甲**：拆为 `手臂生纹/鳞 → 背影亮翼/尾 → 甩镜模糊/黑屏 → 新形态定格`，绝不硬生原地连续变形。
14. **“以物代手”与“静态静物快切”替代高危交互**：用剑鞘挑物代替手指抓取；用柴火铁锅 + 狗闻香替代吃播咀嚼；用马蹄/车轮/掠砖双足拼接奔跑动势避滑步。
15. **纯黑虚空 / 星海 / 数据流隔离系统与创伤记忆空间**（`62/164` 区块，**37.8%**）：进系统加点、功法演武、角色创伤回忆时彻底抽黑现实背景（如锁链局部顶光 `s05_060100`），背景一致性负担归零。
16. **2D 水墨画卷 / 壁画剪影 / X 光透视内视降维法**（`55/164` 区块，**33.5%**）：金色胸骨 X 光内视演脏腑震荡（`s02_030100`）、2D 壁画与水墨山水讲千军万马与创世大场面（`s05_070500`, `091000`）。
17. **全息 UI / 卷轴叠层可视化数值**（`88/164` 区块，**53.7%**）：用 3D 斜角发光光幕/卷轴把抽象设定与战利品可视化，且**空白底生成、文字 100% 后期贴层**。
18. **物理擦拭遮罩（花瓣/芦苇/红袖/陨石）无痛跨场**：用单一高糊前景掠过全屏直接硬切全新时空与色温，零长镜运动成本。
19. **静态意境空镜 + 微动光效替代高算力转场**：原片 5fps 实测 `s04_024800` 证明，2.6 秒近乎静态的高精水墨画 + 0.8 秒圆月卷轴淡入即可造出史诗转场。
20. **多格斜切漫画分屏压缩群像反应**：1 帧同时塞入 3–6 个反派震惊特写，省去 6 次独立镜头生成。
21. **“呆滞人偶态”化短为长喜剧化**：刻意把微僵定格配上冷幽默音效/Q版批注，将静态感转化为反差喜感（`s05_081500`）。
22. **全息光球投影复用旧战斗成片**：战后复盘直接把之前生成的战斗镜头缩进半透明全息光球里播放，零新增渲染成本（`s01_061100`）。
