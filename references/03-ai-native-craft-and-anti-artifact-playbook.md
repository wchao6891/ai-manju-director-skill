# 03｜AI 原生导演工艺、省算力降本与防穿帮避雷手册

> **核心理念**：顶尖 AI 漫剧不是“硬逼 AI 去模拟实拍电影的长镜头多肢体打斗”，而是**用电影级分镜剪辑语法绕开 AI 的物理短板，把算力局限反向包装成高辨识度的视听风格**。本手册直接提炼自 50 区块（749 张拼图 / 12.48 小时）实测记录的 **242 条 AI 工程化技巧** 与 **50 份画质穿帮审计报告**。

## 一、 18 条 AI 原生导演工艺“扬长避短”实战法

### 模块 A｜战斗、暴力与多肢体交互（彻底消灭物理穿模与过审风险）

1. **无接触“前摇 → 反应 → 结果”三段动作跳剪法**
   - **痛点**：AI 生成拳拳到肉、扇耳光、多人缠斗极易出现多手多脚、肢体穿透、打空发软。
   - **解法**：**直接砍掉身体接触的中间帧！**
   - **实片范本**：踹飞强敌只拍 `靴底蹬出特写 → 远景影壁龟裂扬尘 → 敌人嵌墙吐血`（`s01_022200`）；屋内秒杀只拍 `破门木屑爆碎剪影 → 高俯拍坠地`（`s01_015300`）；连扇耳光只拍 `起手腰带 → 过肩捂脸淤青定格 → 乱椅倒地`（`s01_024900`, `041900`）。

2. **2D 黑白线稿 / 水墨泼墨“冲击帧（Impact Frame）”斩杀术**
   - **痛点**：写实 3D 斩首、劈砍、破境容易触发平台血腥审核拦截，且刀刃入肉必穿模。
   - **解法**：在兵刃接触或绝杀瞬间插入 **`1–2 帧（0.1–0.3s）高反差黑白漫画线稿 / 水墨剪影 / 白底红放射线`**，下一帧秒切 **屋檐日芒空镜 / 血泊倒影 / 溅血脸部特写**（`s01_000700`, `001300`, `002800`, `015600`, `045200`, `071400`）。零血腥、零穿模、二次元燃感拉满！

3. **烟雾 / 水雾 / 血雾 / 强光过曝 / 黑屏“断层遮罩术”**
   - **用法**：当动作衔接断层、群战结束或需要隐藏尸体/形变接缝时，直接让全屏翻涌浓烟、气泡白噪、金白冲击波、黑洞涡流或 **1 帧纯黑屏硬切** 吞没画面，烟散/黑屏后直接出结果态（`s01_025100`, `052500`, `054200`, `060700`, `085100`, `s02_000800`）。

4. **“局部单点死锁”破解人兽/巨物交互难题**
   - **痛点**：让 1.7 米主角与百米巨兽同框连续肉搏，AI 必然出现比例乱跳与穿模。
   - **解法**：① **无本体隐形巨妖**：不建巨兽模型，只拍巨浪托船与船夫惊恐（`s01_052100`）；② **微距单点锁死**：如人龙水下死斗，全程不拍全身缠斗，而是死锁“主角单手抠住巨蛟眼眶”极近特写 + 血肉眼眶内视 + 巨兽甩头强动态模糊（`s01_054300–054400`）。

5. **“半透明发光法相 + 光轨流光”代偿实体拼刀**
   - **用法**：多臂神通（如五怒手）绝不直接改人体骨骼长出六条真手臂，而是保留常规双臂实体，在背后叠加**半透明金色发光法相虚影**（`s01_045300`）；高速空中追逐改拍俯视视角下的**红青双色流光光轨追逐**（`s01_001400`）。

### 模块 B｜文戏、口型同步与群像表演（消灭僵硬面瘫与鬼畜嘴型）

6. **物理道具遮嘴法（面具 / 兜帽 / 雨伞 / 手掌 / 门缝）**
   - **实片绝招**：大量常驻配角（如镇魔卫士卒）直接标配**下半脸青铜鬼面具**（`s01_004800`, `022000`, `070200`）；神秘高人藏于**深兜帽重阴影**（`s01_074200`）；密谈时用**手掌捂嘴耳语、雨伞边缘、横刀刀身、门缝竖线或背影 OTS** 自然遮住说话者的嘴部！——既拉满神秘感，又省掉 60% 的口型对位精修。

7. **“眼/唇微距 + 内心 OS”替代全脸长对白**
   - **用法**：面对 20–30 句/分的高密台词，切忌一直给全脸中景硬对口型！高频切换至**只露双眼 ECU（配内心 OS 旁白无需张嘴！）**、**鼻尖以下唇部特写**或**手物微距**（让对白在画外 L-cut 进行），口型穿帮感知度直降 80%。

8. **天然前景容器遮挡下半身（桌面 / 浴桶 / 马鞍 / 窗台）**
   - **用法**：长谈尽量放在**书桌/餐桌/茶案对坐、木桶泡澡、马背半身或窗台前**，利用前景实体自然裁掉腰部以下，把 AI 全部生成稳定性集中到肩上微动作与表情（`s01_072400–072900`）。

9. **“人体背景墙”与“低头跪拜对称阵列”控群像**
   - **痛点**：多人同框走动、交谈极易出现脸盲融混与肢体粘连。
   - **解法**：小队群戏采用 **“主角居中 C 位 + 护卫呈三角扇形静态立于身后”** 稳态构图（`s01_044000`）；百官朝会/众僧/百姓大场面一律采用 **大纵深中轴对称低头跪拜或站桩阵列**（配微小衣摆/呼吸微动），近景只切 1–2 名领头人特写（`s01_014700`, `060500`, `065900`）。

### 模块 C｜变身、换装与复杂生活物理（绕开手指/咀嚼/滑步雷区）

10. **“局部渐进拼接 + 甩镜模糊”替代全身连续变身/穿甲**
    - **禁忌**：严禁写 Prompt 让角色在一个 5 秒镜头里从普通人原地变形长出盔甲和尾巴！
    - **标准解法**：`手臂浮现纹路特写 → 背影亮出尾/翼特写 → 0.4s 动态模糊甩镜/强光 → 完整新形态站姿定格`（`s01_011400`, `033800`, `084800`）；穿甲同理拆解为 `披肩 → 扣甲扣 → 握刀半身定妆`（`s01_085300`）。

11. **“以物代手”规避手指抓握穿模**
    - **实片神来之笔**：搜查破屋杂物不用手翻，改用**剑鞘末端挑开破布并挑起虎头鞋**（`s01_062700`）；传递物件优先给“放上桌面/按住文书/单指轻点”而非双人十指交叉递接。

12. **“静态高质感静物快切”替代吃播、搬运、烹饪与长途奔跑**
    - **吃播/炖肉**：拍柴火、铁锅冒泡汤汁、热粥蒸汽 + **墙外三只狗闻香反应镜**，人物只给 1 帧夹起/闭眼享受，绕开机械咀嚼（`s01_013900`, `051000`）；
    - **清点财物**：粮袋山、银锭箱、绸缎卷静态微距快切，避开多人搬运（`s01_050900`）；
    - **赶路/狂奔**：用 **`马蹄踩泥 → 车轮滚尘 → 掠砖双足 → 晃动灯笼 → 逆光远景骑马剪影`** 拼接动势，彻底规避 AI 跑步滑步与马腿错位（`s01_012000`, `035500`, `072600`）。

### 模块 D｜世界观大场面与超级省算力空间法

13. **“纯黑虚空 / 星海 / 赛博数据流”零背景算力空间**
    - 凡进入系统加点、功法演武、神通推演或 Q 版内心吐槽，**果断彻底抽黑现实背景**！在纯黑虚空里只渲染角色主体 + 发光全息圆环/金色演武小人/二进制代码雨/古画卷轴，背景一致性负担瞬间归零（`s01_020800`, `074400`, `081000`）。

14. **“水墨画卷 / 静态绘本 / 内视透视 CG”替代昂贵大场面**
    - 万妖群像用悬浮古风画卷 + 半透明水墨虚影展示；突破境界用体内骨骼血管发光图或丹田滴露莲花微距可视化；历史战乱用 3 帧静态惨象拼贴 + 人物叠化（`s01_074800`, `s02_002300`, `003900`）。

15. **“空间复用 + 门框光柱站桩”压榨资产复用率**
    - 权威人物出场固定在**门框逆光光柱下站桩**（零室内走位）；同一套悲剧意象空镜（如沉河猪笼）在两段回忆中直接复用情绪翻倍；双人并骑/密室对谈复用同一套固定 3 机位正反打，靠景别微推与眼神推进 200 字/分信息量。

16. **“微距倒影 / 门缝窥视 / 景深错位”零奔袭制造压迫**
    - 巨型反派头颅占满前景 80% 虚化，主角从其耳后景深处探头吐字“在你后面”（`s01_002700`）；用甲片圆镜倒影三人站姿（`s01_005800`）——零动作动画成本，极高导演高级感。

17. **“先冷脸定格 + 突切 Q 版崩溃”反差节奏阀**
    - 把 AI 写实人物表情幅度受限的弱点变成人设优势（高冷面瘫装高手），然后在反差瞬间切黑底 Q 版或肩头 Q 版彻底释放喜剧张力！

18. **“后期剥离原则”：一切文字、书法卡、冲击闪白、速度线均不由 AI 直接生成**
    - 让 AI 只负责生成**干净无字的光影画面与空白发光卷轴/光幕**；所有中文书法名牌、系统数值面板文字、2 帧闪白、相机震动（Camera Shake）、色差故障（Chromatic Glitch）全部在剪映/AE 后期叠加！

## 二、 A / B / C 三级算力预算分层表（工业化成本控制）

不要把所有镜头都送去烧昂贵的顶级 I2V 视频模型！按实片规律严格三分预算：

| 分级 | 占全片镜头比 | 生产工具链 | 适用镜头清单 | 单镜时长 | 成本占比参考 |
| :--- | :---: | :--- | :--- | :---: | :---: |
| **A 级｜核心动态精抽** | **`25–30%`** | 顶级 T2I 首帧 + 旗舰 I2V（Veo / 可灵大师 / 即梦高阶 / Seedance） | 关键打斗起势与招式爆发、法相展开、人物回眸/拔刀/踏步、一镜横移溶变、衣袂光效强互动 | `2.0–4.5s` | ~70% 预算 |
| **B 级｜轻动态微推** | **`45–50%`** | 高精 T2I + 经济型 I2V（`Low Motion`）或 2.5D 景深微推 | 室内外文戏 OTS、双眼微推 ECU、手物微距（茶气/烛火/握拳）、逆光剪影呼吸、远景雨雪雾气 | `1.5–5.0s` | ~25% 预算 |
| **C 级｜静态图 + 后期动效** | **`20–25%`** | 纯高清 T2I 静图 + 剪映/AE（关键帧缩放/震动/闪白/模糊/图层合成） | **所有 `<0.5s` 冲击帧**、2D 黑白线稿斩杀帧、火星特写、黑底书法片名/人物卡、静态水墨回忆图、黑底 Q 版吐槽帧、系统纯图文面板 | `0.15–2.5s` | ~5% 预算 |
